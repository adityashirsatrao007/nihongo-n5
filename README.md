# にほんご N5 (nihongo-n5)

Japanese language study companion for JLPT N5 — vocabulary, kanji, and grammar flashcards.

## Features
- JLPT N5 vocabulary, kanji, and grammar decks
- Spaced-repetition style flashcards
- Built with TypeScript

## Getting Started
